# 多面待ちをどのようにして覚えるか

例えば、 {{2223m}} という待ちが手牌にあったとします。
これは典型的な3面待ちのパターンの1つです。

このパターンでは {{3334m}} のような牌の数字が並行移動した形でも、{{4445m}} のような左右反転した形でも待ちの性質は変わりませんよね？
待ちの形としては暗刻の1つとなりに暗刻と同じ色で1ずれた牌があるというひとつのまとまりとして覚えると思います。
「暗刻+1で、リャン面と+1の牌の同種で待てるタイプだな」というふうに認識すると思います。

このように待ちをパターンとして認識することが、効率よく多面待ちを覚えることの鍵となります。
無数にある多面待ちも、このように場合分けをすることでなんとか覚えられる数量となります。

このアプリでは実際に待ちのパターンに対して `13型` などの名前をつけて、そのパターンを効率的に覚えるような練習メニューを提供しています。
