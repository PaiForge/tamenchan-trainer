# パターン名称の書式と覚え方

{{3334m}} のようなパターンに `13型` というような名前がついています。

このパターンの名前に出てくる13という数字はなんなんだろうと疑問に思われた方もいると思います。
これは、牌式という仕組みを利用してパターンに割り振った数字を名前として利用しています。

牌式とは、 **牌の種類そのもの** ではなく、 **数牌の枚数を配列として表現** したものです。

- 例: {{1112p}} という形なら
  - 1萬： 3枚、2萬：1枚
  - 枚数配列： `[3, 1]`
  - 牌式： **`31`**

ただ、{{2333p}} の牌式は `13` となります。
{{1112p}} と {{2333p}} は実質同じパターンです。
これらを別のものとして扱うのは問題なので、数値として小さい方を正として採用しています。
※ こういった処理を正規化といいます

このように、牌式はパターンの区別に用いているだけなので覚える必要はありません。
牌式を利用した方がパターンを連想しやすいという方は活用していただいてかまいませんが、名前は最低限区別がつくことと、あとは覚えやすかったらなんでもいいのです。

例えば、13型は暗刻+1の形なので、「アンコ（たい焼きなどを連想）とおまけ1」とか、「3+1の形」→「31」→ 「サイ🦏」 みたいな覚えかたでも構いません。
自分がよく知っている事柄や知識と結びつけて、連想がしやすいように意識して覚えることをおすすめします。
